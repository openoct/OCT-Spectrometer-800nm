# OpenOCT Spectrometer 800 nm

This repository contains the optical and mechanical reference designs for the
OCT spectrometer at ~830-840nm. The optical files document the Zemax prescription and
provide a STEP model for reviewing the optical layout and integrating it with
the mechanical design. The mechanical files include CAD models, assembly
instructions, and a parts list for building the instrument from commercially
available optical and mechanical components.

## Repository contents

- [Optics](Optics/README.md): optical layout, Zemax prescription data, STEP
  model, evaluation plots, and component sourcing references.
- [Mechanics](https://github.com/openoct/OCT-Spectrometer-800nm/blob/main/Mechanics/readme.md): mechanical CAD, assembly instructions,
  and parts buy list.
